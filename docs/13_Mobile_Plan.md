# 13 — Mobile and Responsive Plan

MVP is responsive web, not native mobile. Support common desktop and mobile browsers.

- Responsive layout and touch-friendly controls.
- English and Bangla must both work at supported mobile widths.
- Test Bangla glyphs, line wrapping, card heights, search input, menu labels and language switcher on Android Chrome and iOS Safari.
- Test fullscreen behavior separately by browser.
- Handle browser toolbar/viewport changes.
- Do not assume every game supports touch; show instructions.
- Native apps, push notifications, app-store distribution and offline downloads are out of MVP.
