# 14 — Software Development Lifecycle

Lifecycle: discovery → requirements → architecture/ADRs → owner approval → incremental implementation → continuous verification → security/performance review → release approval → monitoring.

Maintain requirements traceability, ADRs, migrations, task evidence, test reports and release notes.

Localization is part of requirements and QA: verify English/Bangla translations, Unicode handling, search, responsive typography and accessibility.

For academic use, report only actual work and measured results. Never fabricate test outcomes, user studies, performance claims or citations.
